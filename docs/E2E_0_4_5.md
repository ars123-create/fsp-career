# Сквозной браузерный сценарий 0.4.5-dev

8 октября 2026. **Основной путь R26: PASS** в пределах отдельного локального
демонстрационного стенда. Один новый вымышленный кандидат и два новых
работодателя созданы через интерфейс. Основной стенд и его записи не менялись.

Стенд: `http://127.0.0.1:8022`, новая база
`data/e2e-0.4.5-host/e2e.sqlite`, macOS / Codex in-app browser (Chromium).
Все изменения для прохождения сценария выполнены видимыми элементами UI.
Прямых вызовов API, исправлений БД, подстановки грейда и чтения закрытых
эталонов для прохождения не было. Ответы получены из показанных условий.

## Неудачные попытки и пределы

Первоначальный адрес в зарезервированном домене `.test` отклонён валидатором
email. Использован демонстрационный `example.org` при отключённом SMTP;
письма остались только в локальном интерфейсе. Селектор по label для грейда
не нашёл поле; после чтения DOM использован доступный combobox по роли.

При клике «Скачать профиль PDF» ожидание события download истекло через
10 секунд. Ошибки в консоли и нового таба не наблюдалось, наличие файла
не подтверждено. Поэтому браузерный перенос PDF **PARTIAL**. Отдельные
181 backend-тест в каждой среде проверяют границу API/PDF; их результаты
не выдаются за успешное браузерное скачивание.

Попытка использовать новый Docker-порт 8021 закончилась connection reset.
Контейнер работал, внутренняя проверка `/api/health` возвращала 200 и 0.4.5;
существующий Docker-стенд 8019 тоже отвечал. Причина проброса не установлена.
Сеть и общие сервисы не менялись. Браузерный сценарий выполнен на отдельном
локальном процессе 8022 из того же проверенного исходного кода. Это не
проверка полного UI внутри контейнера или на независимой машине.

Ответы агента не подтверждают калибровку грейдов, сопоставимость сложности,
защиту от ИИ или качество найма. Независимых участников и оценщиков здесь нет.
Один ответ с неизменным составом не устанавливает преимущество алгоритма.
Другие браузеры, внешний SMTP, новая нагрузка и внешняя сдача **NOT RUN**.
