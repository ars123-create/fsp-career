10 октября 2026. Локальный хакатонный прототип на вымышленных данных. Подготовка файлов отделена от внешней публикации и отправки. Победа, превосходство в реальном найме и production readiness не заявляются.

Участники: Лобутев Арсений Константинович — разработка и алгоритмы; Просветов Александр Сергеевич — продукт, тестирование и презентация. Контакты, фотографии и история команды не выдуманы.

## Изменение

Перенесён закреплённый Mixed-KG m6; UI использует его по умолчанию. API прежних режимов сохранён. Грейд, приватность и зарплатная вилка остаются отдельными серверными правилами. Исследовательский PABBO и новые незавершённые ветки не подменяют продуктовый алгоритм. [Подробности](MATCHING_0_5.md).
