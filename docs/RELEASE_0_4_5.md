## Изменение приложения

Исправлено одно семейство Backend/Middle: прежний вариант принимал два
неверных правила обработки сбоя. В новой рубрике v3 есть ключ только с
откатом и ключ только с потерянным ответом после фиксации. На 200 вариантах
для каждой версии оба неверных правила приняты 200/200 раз в v2 и 0/200 в v3.
Правильный ответ совпал с независимым исполнением SQLite в 400/400 случаях.
Это проверка программных правил одного семейства, не оценка квалификации людей.
Также старый отложенный грейд той же категории не затирает свежий портфель.
Пороги, грейды, старые попытки v1/v2 и исследования подбора сохранены.
Подробности: [ASSESSMENT_V3.md](ASSESSMENT_V3.md).

## Полный браузерный путь

[Новый проход 0.4.5](E2E_0_4_5.md) выполнен отдельно из того же исходного кода
на macOS 8022, с новой базой. Один вымышленный кандидат и два работодателя
созданы через UI. Без ФСП ID, без вакансии компании, 12 заданий v3 и восстановление
ответа после reload. Сохранение и возврат подборки, вилка RUB, согласие и
раскрытие контакта только соответствующей компании прошли проверку.
Другой работодатель видит обезличенный профиль. Ответы теста рассчитаны из
видимых условий, без чтения закрытого эталона или исправления БД.
Единственный ответ работодателя изменил веса, но заменил ноль профилей.
Доступный журнал браузера: 0 error/warn.

**PARTIAL:** ожидание скачивания PDF не вернуло событие, фактический файл
из браузера не получен. Серверные проверки PDF существуют отдельно.
Новый опубликованный Docker-порт 8021 сбрасывал соединение при работающей
внутренней проверке здоровья. Причина не установлена, сетевые сервисы не
перезапускались. Поэтому UI-проход не приписывается Docker или архивному контейнеру.
Новая нагрузка, внешний SMTP и другие браузеры **NOT RUN**.
