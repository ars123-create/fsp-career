# Подбор 0.5.0: Mixed-KG m6

10 октября 2026. В UI «Умный подбор с уточнениями» выбран по умолчанию; API возвращает `mixed-kg-v1`. Для совместимости API без явно указанного режима сохраняет прежний `evidence`. Старые режимы доступны, их результаты не приписываются m6.

После обязательных фильтров используются только подтверждённые баллы по 1–3 навыкам. Пул ограничен 100 профилями; превышение даёт 422 с просьбой уточнить фильтры. Возвращается до пяти кандидатов. Шесть семейств функций полезности учитывают сумму, баланс, слабый навык и насыщение. Вероятности гипотез меняются после попарных ответов работодателя. Следующий вопрос выбирается по ожидаемому улучшению пятёрки за один шаг (Knowledge Gradient). Максимум три слота, включая пропуски. Это конечное приближение, не обучение на истории реального найма.

Ядро перенесено из закреплённого исследования. `backend/app/mixed_engine/SOURCE.json` содержит хеши, настройки и происхождение. Продуктовый адаптер хранит абсолютные векторы старых сравнений: изменение доступного пула не превращает ответ в мнение о другом человеке. Новый вопрос относится только к текущему пулу. Пропуск не меняет оценки; строго доминируемый профиль не вытесняет более сильный. Подтверждённое достижение ФСП используется только при одинаковых векторах навыков. ФСП ID, зарплата, спрос и уточнения не меняют грейд.

Два вычислительных слота ограничивают одновременные временные массивы; кеш сохраняет две компиляции. Это инженерное ограничение памяти, не доказательство SLA.

## Проверки

15 проверок адаптера против неизменённого исследовательского `ParticleSession`: N1/5/6/18/40/100, 1–3 признака, left/right/skip, перестановка пары, удалённый профиль и доминирование. Ещё 7 продуктовых проверок входят в 188 backend-тестов: полный цикл вопросов, порядок признаков, ФСП при равенстве, сохранение и повторный поиск, роли и приватность. Все 22 целевых теста прошли повторно 10 октября.

Фактический браузерный путь: шесть подходящих Middle-профилей, ответ на сравнение Python/SQL меняет одну позицию в пятёрке; сохранённая подборка восстанавливается. Подробнее `E2E_0_5.md`.

## Качество и ограничения

В отдельном замороженном синтетическом исследовании regret ×100: m6 0,955779; P15 1,054081; GP 1,158263; EVOI 1,425472; PABBO 2,076677; равные веса 2,313419. Меньше лучше. Превосходство над EVOI/GP проверено статистически с поправкой на 89 endpoints; сравнения с PABBO и равными весами описательные. Критерии по среднему, семействам, группам и хвосту прошёл только m6 из двух конфигураций-кандидатов. Ограничения интервалов и отрицательные результаты сохранены.

Ни одна из этих цифр не является долей ошибок найма или точностью грейда. Данных рекрутеров нет. 0,234 секунды p95 шага при N100/d3 — локальный замер ядра; GP в этом замере быстрее. Сравнение относится к заданным конфигурациям и синтетической смеси, а не мировому оптимуму.
