# Приоритеты, которые можно задать и исправить

7 октября 2026. Локальное приложение **0.4.3-dev**, режим `weighted`,
алгоритм `direct-weights-v1`. Техническая интеграция PASS; польза для реального
найма, удобство ввода и калибровка навыков **NOT RUN**.

[Аудит 1200 синтетических задач](ELICITATION_AUDIT_0_4_2.md) не установил
универсального преимущества адаптивных вопросов. Поэтому работодатель теперь
может сам задать относительную важность навыков или исправить доли,
предложенные после ответов. Это известное взвешенное среднее, не новый
научный метод и не доказательство превосходства над конкурентами.

## Как работает

В поиске выбрать специализацию и «Задать приоритеты самому». Сначала явно
показаны равные доли. «Изменить приоритеты» открывает редактор для 1–3 навыков.
Важность означает пользу одинакового роста результата проверки с 50% до
100% при остальных равных условиях. Допустимы числа от 0 до 100; сумма
не обязана быть 100, но должна быть положительной. Пустой запрос начинает
с равных весов. Неполный, лишний или недопустимый набор API отвергает.

После нормировки веса умножаются на наблюдаемые результаты проверки навыков;
выбирается до пяти профилей с наибольшим средним. Все обязательные фильтры
применяются раньше. Навык с нулевым весом остаётся обязательным. При равной
оценке действует прежнее правило подтверждённого достижения ФСП, затем ID.
Грейд и разрешения на контакты не зависят от весов. Сам ФСП ID преимущества
не даёт. В отличие от режима вопросов, здесь нет ограничения пула в 100
профилей; корректность отдельно проверена на 101 профиле. Это не нагрузочный
замер и не обещание масштабируемости.

В режиме уточнений тот же редактор предлагает округлённые до двух знаков
доли. До нажатия «Применить приоритеты» они не меняют выдачу. Применение
переключает запрос на ручные веса и очищает историю сравнений. Обратная
кнопка «Уточнить через вопросы» начинает новый диалог с равных приоритетов.
История и ручные веса не смешиваются. Сохранение сохраняет выбранный режим,
веса и исходный состав; после reload «Обновить состав» пересчитывает его.
