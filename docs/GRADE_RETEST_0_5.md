# Синтетическая повторяемость текущей проверки навыков

10 октября 2026. Проверены две формы текущего банка v3 для 4 320 синтетических профилей: 8 640 прохождений, 103 680 ответов. Это проверка поведения рубрики при заданных моделях ответов; человеческая калибровка не проведена.

Использована реальная build_test/score_test из продукта. История и 90-дневный запрет смены категории не участвовали: стабильность не создавалась искусственно сохранением старого грейда. Для каждого заявленного уровня сравнивается результат «подтверждён / не подтверждён».

## Как интерпретировать

Вероятность правильного ответа задаётся логистической моделью с фиксированной способностью, случайным профилем навыков и сложностью формы. Все параметры гипотетические. Проверены обычные варианты, существенная разница сложности форм и один слабый навык. Положительная разделяющая сила частично заложена монотонной моделью ответов; эти числа не доказывают качество заданий для людей.

Несовпадения остаются в отчёте. Пороги 75% в целом и 50% по каждому навыку/практике не менялись после результатов. Программные инварианты прошли; достаточность повторяемости для реального присвоения грейда не установлена.

Для каждого семейства приведена разница долей правильных ответов между θ≥1 и θ≤−1. Это отдельная группировка по заданной способности, не по суммарному тестовому баллу. Матрицы результатов и разрезы по способности: `output/validation/grade-retest-v1/summary.json`; все пары: `pairs.jsonl` рядом.

Воспроизведение: `python validation/grade_retest/run.py /tmp/fsp-grade-retest-new` из корня проекта. Нужна новая несуществующая папка. Протокол и хеши исходников сохраняются перед расчётом.

Источники: [формула ICC](https://douglasrizzo.com.br/catsim/_modules/catsim/irt.html#icc), [Cohen κ](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.cohen_kappa_score.html).
