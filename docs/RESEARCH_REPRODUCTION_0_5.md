## Восстановление полного набора

Из корня проекта, нужен Python 3.11+ и около 4,5 GB свободного места:

```sh
python3 scripts/restore_domain_evidence.py /tmp/fsp-domain-replay
```

Папка должна отсутствовать. Скрипт проверяет SHA256 протоколов, каждого закреплённого исходника, полных строк и восстановленных worker-shards. Дублирование исходных snapshots и shards в ZIP заменено восстановлением из тех же байтов. Ничего не генерируется заново и случаи не отбрасываются.

В копиях preflight меняется только абсолютный путь `workspace`, необходимый строгому загрузчику. Исходные preflight сохранены рядом с суффиксом `.original`; `RELOCATION.json` записывает оба хеша. Протоколы, ответы, результаты и аналитический код остаются побайтно прежними. Это транспортная адаптация, не исходный повтор без изменений метаданных.

## Повтор анализа

Замороженный загрузчик намеренно проверяет окружение: Python 3.12.14, NumPy 2.4.4, SciPy 1.18.1, Torch 2.11.0, BoTorch 0.18.1, GPyTorch 1.15.2, Darwin arm64 / cpython-312-darwin. На другом окружении он выдаст ошибку; это ограничение строгого повтора, а не требование веб-приложения. Не удаляйте проверку, чтобы объявить новый результат исходным.

В указанном окружении из корня проекта:

```sh
python -m research.frontier_2026.domain_transfer.analyze \
  --quality /tmp/fsp-domain-replay/domain-quality-v1 \
  --timing /tmp/fsp-domain-replay/domain-timing-v1 \
  --out /tmp/fsp-domain-analysis-new
```

Выходная папка должна отсутствовать. Анализ включает 49 999 bootstrap-повторов; он существенно дольше чтения готового отчёта. Новый файл будет иметь другую дату и хеши транспортных preflight; сравнивать следует метрики, интервалы и решение. Повтор на тех же seeds не является новой независимой проверкой.

Новый запуск всех оптимизаторов по исходному протоколу намного дороже и не нужен для запуска продукта. Исследование не доказывает превосходство над всеми реализациями PABBO/GP, качество найма или производственную готовность.
