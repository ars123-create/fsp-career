`scripts/build_release_media.py`, `scripts/package_release.py`. Для авторинга

приложения он не нужен. Подробный маршрут демонстрации: [DEMO_RU](DEMO_RU.md).

## Проверка выпуска

Предварительный ZIP распакован в отдельный каталог. Все 68 файлов приложения
совпали с проверенной сборкой по SHA256. Docker build из распакованной копии
прошёл и дал тот же образ `7f8fddd9448d`; использовались кеши этого компьютера.
В новом контейнере без сети, с read-only rootfs и пустой SQLite в tmpfs:
миграции + alembic check, seed v1, новая попытка v2 (12/6), уточняющий top-5 с
вопросом и index HTTP200 — PASS. Рабочая база не подключалась.
Первый проверочный скрипт неверно назвал режим `preference_v3`, получил422;
после исправления на документированный `preference` сценарий прошёл.
Код приложения при этом не менялся.

Финальный ZIP дополнен только документацией и результатами проверок;
пакетировщик повторно сверяет CRC и SHA256 каждого файла. `.env`, рабочие БД,
кеши и локальные секреты исключены. Хеш ZIP — в соседнем SHA256SUMS.txt;
manifest находится и внутри ZIP. Новая независимая машина NOT RUN.
OpenAPI точно совпал с текущим приложением (45 операций).

13/13 слайдов прошли визуальный QA, 7/7 страниц документации просмотрены.
Все13 изображений PDF совпали с финальными рендерами. MP4 полностью
декодируется без ошибок; 88 секунд/1920×1080/24fps/H.264 подтверждены ffprobe.
Источники и границы: output/validation/release-0.4-*.json и
[PRESENTATION_QA](PRESENTATION_QA.md). Исходный шаблон и ZIP0.1.0 не изменились.

После упаковки проведён полный браузерный сценарий R26 на том же коде
0.4.0-dev: [протокол и границы](E2E_0_4.md),
`output/validation/e2e-0.4-browser.json`. Основной ZIP, презентация, PDF и
