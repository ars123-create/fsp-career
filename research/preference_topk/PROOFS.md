# Условные математические свойства

Известная байесовская теория решений; не доказательство научной новизны.
См. Viappiani & Boutilier 2010, определение EPU/EVOI, и DESIGN.md.

Пусть h — конечная гипотеза с вероятностью p_h, u_hi∈[0,1] — её полезность
кандидата i. Допустимы все множества из k кандидатов, уже прошедших обязательные
фильтры. Полезность множества — сумма, а не лучший один человек в нём.

1. **Оптимальная рекомендация при заданных сведениях.** По линейности ожидания
   EU(S)=Σ_{i∈S}Σ_h p_h u_hi. Следовательно, top-k по средним s_i=Σ_h p_h u_hi
   максимизирует EU(S). При одинаковом posterior «улучшенное» ранжирование не
   может дать больше этой ожидаемой суммы. Оно может оптимизировать другую цель.

2. **Вычисление вопроса без нестабильного деления.** Для бинарного ответа
   L_h=P(left|h), определим a_i=Σ_h p_h L_h u_hi, b_i=s_i−a_i. При положительной
   вероятности ветви её posterior scores равны a_i/P(left), соответственно
   b_i/P(right). Положительная однородность суммы top-k даёт
   EPU=TopKSum(a)+TopKSum(b). Формула сохраняется при нулевой вероятности ветви:
   её вклад равен нулю. Для каждого вопроса EVOI=EPU−TopKSum(s).

3. **EVOI ≥ 0 только в среднем внутри модели.** В каждой ветви можно оставить
   исходный набор S*. Поэтому EPU≥Σ_i∈S*(a_i+b_i)=TopKSum(s). Выбор максимального
   EVOI среди перечисленных пар оптимален для одного шага среди этих пар.
   Это не оптимальность всей цепочки вопросов и не гарантия улучшения после
   каждого фактического ответа. Ошибочный ответ способен ухудшить реальный top-k.

4. **Равное количество информации.** Все baseline получают свои ответы с тем
   же бюджетом и используют одну posterior ranking. Различия результатов
   относятся к выбору вопроса. Сравнение с нулём вопросов — только отдельный
   диагностический контроль, не доказательство преимущества над другими
   интерактивными алгоритмами.

5. **Шум и отказ.** L_h=ε/2+(1−ε)sigmoid((u_ha−u_hb)/τ), τ>0, ε>0, поэтому
   обе ветви имеют положительную вероятность. Противоречивые ответы дают
   конечный posterior. Отказ не является выбором и ничего не обновляет.
   Одинаковые независимые ответы можно переставить: произведение likelihood
   не меняется. Это предполагает условную независимость, а не доказывает её.

6. **Квадратура.** Для uniform simplex средний исходный вес 1/d. Симметризация
   делает его точным в конечной модели. В d=3 условное математическое ожидание
   при w0≥w1 равно (1/2,1/6,1/3); равное усреднение вершин области даёт другую
   величину. Проверка этого момента диагностирует корректность интегрирования,
   но не устанавливает uniform prior для работодателей. Численный EVOI точен
   для конечной модели и лишь приближает интеграл непрерывного prior.

Все утверждения обусловлены полезностью, prior и response model. При неверных
предпосылках и для найма людей таких гарантий нет. Контрпример с ошибочным
ответом, полный независимый перебор наборов и проверка моментов — в test_core.py.
