# Проверяемые ошибки в задании о повторе после сбоя

8 октября 2026, B04/B09, R05/R18. Исправление содержания, не калибровка грейда.
Прежний ход работы дал технически правильные эталоны, но не проверил,
отличается ли ответ при неверном понимании заявленных правил.

В `api_retry_ledger` рубрики v2 каждый из трёх ключей в итоге имеет `ok`.
Поэтому игнорирование всех стадий и ошибочное игнорирование `after_commit`
дают правильные итоговые числа. Пример разработки: seed 948500, правильный
остаток 362 и 3 записи; обе ошибочные стратегии дают те же числа.

Исправление: для Backend/Middle новая форма содержит четыре роли ключей:
откат с последующим успехом; только фиксации с потерянным ответом;
только откат; обычный успех с повтором. Всего семь запросов, как раньше.
Ключи, суммы, исходный запас и допустимое перемешивание меняются по seed.
Новый результат обязан отличаться от трёх заранее выбранных неверных правил:
игнорировать стадию, считать потерянный ответ откатом, повторно списывать
при одинаковом ключе. Это проверка конкретных программных моделей ошибок,
а не частоты ошибок людей или защиты от ИИ.

Изолированный прототип использует существующий формат заданий и stdlib.
Независимый эталон выполняет SQLite INSERT/UPDATE/COMMIT/ROLLBACK.
Hypothesis 6.168.5, MPL-2.0 — готовый генератор входов для технических свойств.
Его официальный минимальный пример запускается перед адаптацией.
PrairieLearn изучен как полноценная платформа случайных вариантов; запуск
новой LMS не нужен для замены одного семейства. Внешний код не копируется.

Разработка: seeds 948500–948519 (первый уже просмотрен).
Окончательная техническая проверка: 949000–949199, 200 задач на каждую версию.
До запуска зафиксировать SHA256 прототипа, оценщика, baseline v2 и этого файла.
После просмотра не менять набор/модели ошибок ради цифр; при проблеме
сохранить неудачный результат и выпустить отдельный протокол.
Результаты публикуются по каждому ошибочному правилу, включая отрицательные.
Нет доверительных интервалов для людей: наборы искусственные и конструктивные.

Критерии допуска: правильные ответы совпадают с независимым SQL;
в новом семействе три ошибочных правила отвергаются; 12/3 заданий и 75/50/50
сохранены; другие семейства неизменны; старые v1/v2 воспроизводятся и
завершаются по прежним правилам. Новые попытки используют v3. Короткая v3 не
переписывает портфель v2 без новой полной проверки. Грейды, история,
исследования и уже собранный комплект 0.4.4 не пересчитываются.

Экспертный пакет 0.4.4 с 48 заданиями остаётся снимком прежнего банка.
Новые варианты потребуют отдельной независимой оценки; её пока нет.
