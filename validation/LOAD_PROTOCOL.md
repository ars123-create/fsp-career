# Протокол технического замера v1

Зафиксирован 2026-10-07 до запуска. Сборка 0.1.0. Цели команды, не обещания организатора: 30 параллельных клиентов; p95 поиска и профиля < 2 секунд; 0 неожиданных HTTP-ошибок.

Docker Compose: один процесс uvicorn, PostgreSQL 16, 24 опубликованных синтетических профиля. Среда Colima linux/aarch64: 2 CPU, 2054311936 байт RAM. Генератор нагрузки работает на том же Mac через loopback. Два демонстрационных работодателя и кандидат; 30 виртуальных клиентов делят эти три сессии. Это тест одновременных запросов, а не 30 независимо зарегистрированных людей.

Перед измерением 3 прогревочных цикла. Затем 30 корутин выполняют по 30 запросов последовательно без пауз: поиск, просмотр профиля и просмотр приглашений чередуются. Всего 900 запросов; HTTPX AsyncClient с пулом 30 соединений и тайм-аутом 20 секунд. Тайминги измеряются perf_counter на клиенте, nearest-rank p50/p95, без исключения ошибок/хвостов. PDF, регистрация с Argon2 и SMTP не входят в нагрузку; их проверяем отдельным сценарием.

Нельзя выдавать этот короткий замер на 24 профилях за capacity planning для большой базы или внешнего сервера. Повторный запуск имеет отдельный файл результата; исходный замер сохраняется. Версии и SHA256 прикладных исходников записываются вместе с результатом.
