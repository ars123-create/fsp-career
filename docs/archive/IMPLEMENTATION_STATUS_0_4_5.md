## Обнаружено и исправлено

Сериализация SQLModel после commit, гонки приглашений, исходный состав подборки после снятия публикации, повтор ссылки email, возврат эталонов только после завершения, сохранение навыков не из текущей категории, утечка введённого секрета в ошибке валидации, фильтры прежнего запроса при новом тексте и фокус закрытого мобильного меню.
