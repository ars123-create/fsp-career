# ФСП / Карьера — продуктовый ролик

10 октября 2026. Монтаж реальных экранов приложения 0.5.1: 1920×1080, 30 fps,
2214 кадров / 73,8 секунды, H.264, без звука. Курсора и имитации ввода нет.
Авторские композиция и подписи; переходы, плавное кадрирование, рамки акцентов.

## Воспроизведение сборки

```sh
npm ci
npx tsc --noEmit
npx remotion still FspProductFilm preview.png --frame=1122
npx remotion render FspProductFilm overview.mp4 --codec=h264 --crf=18 --pixel-format=yuv420p --concurrency=2
```

При наличии Chrome можно добавить `--browser-executable='/absolute/path/to/chrome'`.
Иначе Remotion предложит свой браузер. Версии закреплены в package-lock.json:
Remotion / CLI / fonts 4.0.534, React 19.2.3, TypeScript 5.9.3.
Рабочая станция: macOS arm64, Chrome for Testing из Playwright Chromium 1247.
Сохранённые PNG не требуют работающего сервера или доступа к аккаунту.

## Происхождение экранов и границы

`public/screens` — снимки работающего приложения 0.5.1, сделанные 10 октября
через Playwright на отдельной свежей демобазе. Исходный viewport 1440×1000,
deviceScaleFactor 2; некоторые изображения сняты с конкретного блока DOM.
Обезличенные подборки, персонажи, компания и контакты вымышлены.
В UI выполнены обычный вход обеих ролей, поиск, ответ Б на сравнение,
принятие подготовленного приглашения и открытие контактов у работодателя.
Между этими действиями БД вручную не исправлялась.

Это монтаж возможностей, а не непрерывная запись сквозного теста:
- показанное практическое задание не сдавалось в этой съёмке;
- результат 100% — существующая запись демоистории; это подписано в кадре;
- подборка Middle и приглашение Junior — разные иллюстрации;
- скрыты браузерная рамка, курсор и ввод паролей;
- кадрирование и подписи не меняют значения в интерфейсе.

Монтаж не доказывает качество найма, научную новизну алгоритма или независимую
калибровку грейда. Сквозные технические проверки находятся в документации
приложения, отдельно от этого ролика.
