# Сквозной браузерный сценарий 0.4.0-dev

7 октября 2026. **R26: PASS** в границах локального демонстрационного стенда.
Один новый вымышленный кандидат прошёл последовательный путь регистрации,
проверки навыков и приглашения. Новый второй работодатель использован для
проверки изоляции контактов. Существующие демо-аккаунты и история сохранены.

Стенд: `http://127.0.0.1:8018`, macOS, Codex in-app browser.
Все изменения состояния выполнены через видимые элементы интерфейса CUA.
Прямых запросов к API для прохождения сценария, исправлений БД, подстановки
грейда и чтения закрытых эталонов не было. Ответы рассчитаны по показанным
условиям заданий. Это работа агента с вымышленными данными, не участник пилота.

## Что этим не подтверждено

- Ответы агента и 100% не калибруют сложность, границы грейдов или качество найма.
- Один ответ с неизменной пятёркой не устанавливает преимущество алгоритма.
  Замороженные исследовательские результаты и отрицательные сценарии сохранены.
- Внешняя доставка почты не проверялась: письмо осталось на локальном стенде.
- Здесь проверены UI и DOM. Граница доступа в API/PDF проверяется отдельными
  backend-тестами; PDF через браузер в этом проходе не скачивался.
- Это последовательный проход со снимками, без непрерывной видеозаписи.
- Публичная установка, независимый пользовательский пилот и отправка на
  платформу хакатона не выполнены. Общая готовность к победе не заявляется.
