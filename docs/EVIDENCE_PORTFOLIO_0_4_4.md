# Сохранение результатов семейств в 0.4.4

7 октября 2026. Техническая проверка PASS; калибровка навыков на людях NOT RUN.
Ранее короткая проверка заменяла весь снимок навыка одним ответом: например,
75% по четырём семействам превращались в 0% по одному. В 0.4.4 она обновляет
только проверенное семейство, сохраняя остальные наблюдения. Это исправление
учёта результатов, не новый метод определения профессионального уровня.

## Правило обновления

- Успешная основная проверка задаёт фиксированный набор семейств для своей
  специализации, грейда и версии рубрики. Процент — среднее последних
  наблюдений по этим семействам, а не вероятность владения навыком.
- Короткая форма заменяет наблюдение только своего семейства. Повтор не
  увеличивает покрытие. При четырёх семействах один ответ меняет среднее
  максимум на 25 пунктов. Новая основная форма может изменить весь набор.
- Сводная дата — самое старое действующее наблюдение; при необходимости
  показывается и самая новая дата. Один свежий ответ не обновляет дату всех
  остальных результатов. Семейства не объявляются независимыми измерениями.
- Грейд определяется прежней отдельной рубрикой. Неудача не понижает его.
  Повтор завершения и повтор получения ранее выданного грейда не откатывают
  свежие результаты. Получение старого отложенного грейда той же категории
  сохраняет более новый набор наблюдений.
- История восстанавливается только при наличии подходящей успешной основной
  формы и однозначного порядка событий той же рубрики. Если оснований нет,
  короткий результат сохраняется в истории, прежний профиль сохраняется,
  интерфейс объясняет необходимость основной проверки. Массового пересчёта
  прежних профилей миграция не выполняет.

Контракт записан до интеграции в
[DESIGN.md](../validation/evidence_portfolio/DESIGN.md). Прототип побайтно
перенесён в `backend/app/evidence_portfolio.py`; адаптер — `skill_projection.py`.
Внутренние ссылки на попытки не отдаются в публичном профиле. Миграция
`20261007_03` добавляет JSON-поле с пустым значением. Источники и лицензии:
[реестр](REUSE_REGISTER.md).

## Границы результата

Банк заданий, пороги и замороженные исследования подбора не изменены. Остались
непроверенными сложность и сопоставимость форм на людях, устойчивость к
заучиванию и внешнему ИИ, связь баллов с работой. Новое правило не обучено на
данных найма и не объявляется статистически оптимальным. Нагрузочная проверка
новой записи портфеля NOT RUN. R05/R12/R18 остаются PARTIAL.
