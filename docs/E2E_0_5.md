3. PASS: работодатель выбирает backend/Middle/удалённо. m6 рассматривает шесть профилей; ответ на вопрос Python/SQL меняет одну из пяти позиций. Ранее созданная через UI подборка «Backend · приоритет Python · m6» восстанавливается.
