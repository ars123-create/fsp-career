# Выпуск 0.5.1 — проверенный комплект для жюри

10 октября 2026. База: проверенный выпуск 0.5.0. Алгоритм m6, банк заданий, правила грейда и контракт приглашений не менялись.

## Изменения

- С главной удалены два автоматических входа в демопрофили. Остались обычный вход и регистрация.
- Два вымышленных аккаунта используют обычную форму /login: candidate@demo.fsp.test и employer@demo.fsp.test. Публичный пароль обоих — 12345678, по прямому запросу автора. Памятка: TEST_ACCOUNTS.txt. Реальные почтовые ящики не создавались.
- Эти входы и их ранее выданные токены не работают при FSP_DEMO_MODE=false. Обычная регистрация и смена пароля по-прежнему требуют минимум 10 символов.
- Повторный запуск обновляет только пароль этих явно демонстрационных пользователей; профили и приглашения сохраняются. Учётные записи без is_demo не изменяются.
- Актуальный обзор переснят по пользовательскому примеру Geoscan: реальный headless Chromium + Playwright recordVideo, подписи и маркеры нажатий, затем FFmpeg → H.264. 140,50 секунды, 1440×900, 30 кадров/с, без звука. 17 сцен: обычный вход, профиль, три практических ответа, новый результат, подбор, уточнение, новое приглашение, согласие, контакты и скачивание PDF. Между действиями БД не исправлялась. Вырезаны ожидания и выполнены переходы между двумя кабинетами. Исходник: authoring/fsp-live-demo/.
